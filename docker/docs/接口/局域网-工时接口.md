# 工时接口（局域网）


> 版本 v1.0 ｜ 状态：已实现 ｜ 更新：2026-11-27
| 项 | 值 |
|---|---|
| 服务 | 工时网关（`docker/gateway`）|
| Base URL | `http://<宿主机IP>:3090` |
| 鉴权 | 无（仅限内网使用，请勿暴露到公网）|
| 编码 | 请求与响应均为 UTF-8 JSON |

> 网关只绑定内网网卡 `192.168.2.170:3090`（本机也从该地址访问，`127.0.0.1` 不通）；换机器时改 `GATEWAY_BIND`。

## 1. 项目清单

```
GET /projects
```

```json
[
  { "id": "metahuman", "name": "数字人 POC", "host": "metahuman", "port": 3084,
    "status": { "running": true, "health": "healthy", "image": "dsh-collaborationagent:…" } }
]
```

## 2. 单个项目的工时

```
GET /timesheet?project=<项目id>[&plan=<计划号>]
```

- `project`：清单里的 `id`；
- `plan`：可选，省略时返回该项目**全部计划**。

响应（v2）：

```json
{
  "schema_version": 2,
  "project": { "id": "lafinger-agent/web-test", "name": "Web项目测试" },
  "plans": [
    {
      "number": 1,
      "url": "https://github.com/…/issues/1",
      "title": "计划：新增访问计数器页面",
      "content": "…",
      "roles": [
        {
          "key": "design", "name": "设计岗", "person": "陈小二",
          "tasks": [
            {
              "number": 2, "url": "…", "title": "任务：…", "content": "…",
              "pull": { "number": 4, "url": "…", "title": "…", "content": "…" },
              "timestamps": {
                "requirement_start": "2026-11-24T09:57:00Z",
                "plan_published":    "2026-11-24T10:02:00Z",
                "submitted":         "2026-11-24T11:30:00Z",
                "plan_completed":    "2026-11-24T15:00:00Z"
              },
              "durations": { "planning": 0.08, "response": 1.47, "closing": 3.5, "total": 5.05 },
              "missing": []
            }
          ]
        },
        {
          "key": "approver", "name": "管理岗", "person": "陈锦鸿",
          "tasks": [],
          "coordination": {
            "timestamps": { "requirement_start": "…", "plan_published": "…", "plan_completed": "…" },
            "durations": { "confirm": 0.08, "close": 4.97 }
          }
        }
      ]
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `plans[].roles[]` | 岗位分组；`tasks` 为该岗位的任务 |
| `tasks[].timestamps` | 四个时刻：需求开始 / 计划发布 / 首次提交 / 计划完成（缺失则不出现）|
| `tasks[].durations` | 相邻时刻相减（小时）：`planning` / `response` / `closing` / `total` |
| `tasks[].missing` | 缺失时刻的语义名，如 `["submitted"]` |
| `tasks[].pull` | 结果 PR；没有 PR 时**整个字段缺失** |
| `roles[].coordination` | 仅管理岗：三时刻 + `confirm` / `close` 两段等待，无任务 |

## 3. 全部项目的工时

```
GET /timesheet/all
```

```json
{ "projects": [ { "id": "metahuman", "name": "数字人 POC", "plans": [ … ] } ],
  "errors":   [ { "id": "web-test", "status": 502, "error": "…" } ] }
```

某个实例不可达时，其余项目照常返回，失败项进 `errors`。

## 4. 示例

```powershell
# 单个项目
Invoke-RestMethod "http://192.168.2.170:3090/timesheet?project=metahuman&plan=1"

# 全部项目
Invoke-RestMethod "http://192.168.2.170:3090/timesheet/all"
```

```bash
curl -s "http://192.168.2.170:3090/timesheet?project=metahuman&plan=1"
```

## 5. 错误码

| 状态 | 场景 |
|---|---|
| `404` | `project` 不存在 |
| `502` | 目标实例不可达 |
| `500` | 网关内部错误（响应体带原因）|

## 6. 注意

- 网关默认绑定 `0.0.0.0:3090`，**没有鉴权**，只应在受控内网使用；需要时用 `GATEWAY_BIND` 限定网卡。
- 直接访问某个实例（如 `http://<IP>:3084/orchestrator/api/timesheet`）需要该实例的 `DSH_ORCHESTRATOR_TRUSTED_HOSTS` 含这个内网地址，并带请求头 `x-orchestrator-request: 1`；**经网关访问不需要**。
- 前端跨域 fetch 会受浏览器同源限制；建议由自己的后端转发，或把页面部署到同一来源。
