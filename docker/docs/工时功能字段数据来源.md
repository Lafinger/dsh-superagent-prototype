## 1. 字段来源总表

| `plan` | C | 请求参数 `?plan=N`，并用接口返回的 `number` 核对 | `http.ts` → `timesheetView` | `plan` 非正整数 → 400；计划不存在 → 404 |

| `plan_content` | G | 同上 → `body`（Markdown 原文）| 同上 | 空正文时为 `""` |
| `task` | G | `GET /repos/{repo}/issues?state=all&per_page=100`，筛 `labels` 含 `task` 且正文命中 `归属计划：#N` | `collectTimesheet` / `collectAllTimesheets` | 无任务时 `rows: []` |
| `task_url` | C | 拼接 `/issues/{task}` | `buildRows` | — |
| `task_title` | G | 列表项 `title` | 同上 | — |
| `task_content` | G | 列表项 `body` | 同上 | — |
| `pull` | G | 同一次列表请求中带 `pull_request` 的项 → `number` | `asPull` | 任务无 PR → 四个 `pull*` 字段整体缺失 |
| `pull_url` | C | 拼接 `/pull/{n}` | `buildRows` | — |
| `pull_title` | G | 列表项 `title`（PR 在 issues 列表里也有标题）| `asPull` | — |
| `pull_content` | G | 列表项 `body` | `asPull` | — |
| `role` | C | 正则解析 `task_content`：`**角色**：X · Y · 顺序 n` | `parseTaskMeta` | 模板不符 → `"—"` |
| `person` | C | 同上 | 同上 | 模板不符 → `"—"` |

| `response` | C | `b3 − b2` | 同上 | 同上 |
| `closing` | C | `b4 − b3` | 同上 | 同上 |
| `total` | C | `b4 − b1` | 同上 | 同上 |
| `missing` | C | 上述四时刻中取不到的代号列表 | `buildRows` | 全齐为 `[]` |

## 2. 与 GitHub 的调用清单

| 场景 | 接口 | 次数 |
|---|---|---|
| `?plan=N` | `GET /repos/{repo}/issues/{N}` | 1 |
| `?plan=N` | `GET /repos/{repo}/issues?state=all&per_page=100` | 1 |
| 不带 `plan` | `GET /repos/{repo}/issues?state=all&per_page=100` | 1 |
| ~~PR 详情~~ | ~~`GET /repos/{repo}/pulls/{n}`~~ | **已移除**（改为读列表里的 `pull_request.merged_at` 与 `body`）|

- 实测耗时：`?plan=1` ≈ 2.1s；全部计划 ≈ 1.1s。
- **无缓存**：每次请求都实时调用，GitHub 抖动会直接返回命令错误。

## 3. 本地 SQLite 的读取清单

| 表 | 读取方式 | 用途 | 是否改结构 |
|---|---|---|---|
| `ticket` | `store.tickets.list()` | 取工单 `origin.triggerId` 与 `inputs[].triggerId` | 否 |
| kv | store.get(KV.planLink(n)) | **B1 首选项**：计划对应的需求消息时间（由报告工具写入）| 否（新增一个 KV 家族 plan-link:，不改表）|
| `trigger` | `store.triggers.get(id)` | 取消息 `at` 与 `text`（判断是否含 `/issues/N` 链接）| 否 |

> 框架自带 schema 11，表定义在 `src/app/store.ts:64-80`；本次**未新增表、列或迁移**。

## 6. 结论：侵入性评估

- **字段层面：零侵入**。全部是"读 GitHub + 读框架自带的 ticket/trigger + 本地计算"，没有新增存储、没有改表、没有写回业务数据。
- **行为层面：有改动**。合并时机与下游放行写在提示词里（软约束），局域网访问是新增的入口白名单（默认关闭）。
- **可回退性**：删除 `src/sources/timesheet.ts`、`src/app/timesheet-data.ts` 及 `http/runtime` 三处挂载即可完全移除；数据库与仓库数据不受影响。
