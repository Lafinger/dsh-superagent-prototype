## 文档状态

每篇文档标题下都有一行元信息，格式统一为：

```markdown
> 版本 v1.0 ｜ 状态：已实现 ｜ 更新：2026-11-27
```

| 状态 | 含义 |
|---|---|
| **已实现** | 与当前代码一致，可直接作为使用或验收依据 |
| **未实现（设计方案）** | 设计已完成，代码尚未实现 |
| **调研（未实施）** | 方案对比与结论，未进入实施 |
| **操作指南** | 环境搭建与账号配置步骤 |

## 维护约定

1. **只保留两类内容**：当前已实现的方案、尚未实现的方案（设计与调研）。客户需求原件、测试用例与测试截图不在此目录保存。
2. **新增文档**：按主题放进 `接口/`、`设计/`、`部署/`；设计取舍写成 `adr/NNNN-简题.md`（英文短横线命名，编号递增）。
3. **重命名或移动**：必须同步修改 `README.md` 与本目录内其他文档的链接（相对路径）。
4. **元信息**：新增或实质修改文档时，更新标题下的版本号、状态与日期。
5. **私密配置不入库**：`.env`、`gateway/defaults.env` 等含 token 的文件由 `.gitignore` 排除，只保留示例。

> 早期归档的客户需求与测试材料已于 2026-11-27 移出本目录；需要追溯时从 git 历史（提交 `14bafb9`、`c735769`）取回。
