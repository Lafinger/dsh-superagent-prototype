# 访问计数器增加「重置」功能

| 版本 | 交付周期 | 基础 |
|---|---|---|
| v1.0 | 2 个工作日 | 已上线的访问计数器页面（本机记录口径）|

## 背景

计数器目前只能一直累加，演示时想从头开始只能清浏览器缓存，不方便。需要一个重置入口。

## 需求

1. 页面增加一个「重置」按钮，点击后**当前计数清零**，页面立即显示 0；
2. 清零后仍按原口径保存在本机（localStorage），刷新或重开页面依旧是 0；
3. 清零后再次访问页面，计数从 1 开始重新累计；
4. 其余行为保持不变（现有展示方式、本机记录口径都不改）。

## 不做

- 账号体系、后端接口、多人共享计数；
- 计数历史与统计报表。

## 验收

1. 点「重置」→ 页面显示 0；
2. 刷新页面 → 仍是 0；
3. 再访问一次 → 显示 1；
4. 原有累加与展示逻辑不退化。

## 交付

- 设计岗：产品说明（含按钮位置、交互与文案）+ 页面视觉稿；
- 实施岗：`app/web/` 下可运行页面，附一张自测截图；
