# 数字人 POC · 知识库功能需求

| 版本 | 交付周期 | 基础 |
|---|---|---|
| v1.0 | 5 个工作日 | 已交付的数字人语音交互 POC |

## 背景

现有 POC 能语音对话，但回答是模型自由生成的，口径不可控。需要加一个**知识库**：常见问题按我们预设的答案回答。

## 需求

1. 维护一份「问题—答案」清单，CSV 导入即可，支持别名和启用/停用。
2. 用户提问先查知识库：命中就按标准答案播报，字幕标注「来自知识库」。
3. 没命中只说统一兜底话术（如"这个问题我暂时答不上来"），**不转普通闲聊**。
4. 改完导入即生效，不需要重启。
5. 现有语音对话、打断、数字人形象保持不变。

## 不做

文档自动解析、语义检索/向量库、多语言、权限审批、与真实业务系统对接。

## 验收

1. 新增一条知识，提问能命中并播报标准答案
2. 修改答案后立即生效
3. 停用后不再命中
4. 用别名提问也能命中
5. 未命中播出兜底话术
6. 字幕与语音内容一致
7. 10 条验收问答全部答对
8. 全程不重启，原有功能不退化

## 交付

- 第 3 个工作日：中期演示（能命中一条）
- 第 5 个工作日：最终交付
- 交付物：可运行程序、CSV 模板与使用说明、10 条验收记录、1 分钟录屏
