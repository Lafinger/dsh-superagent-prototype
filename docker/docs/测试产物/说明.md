# Todo 单页应用 · 使用说明

本目录是「个人待办清单（Todo）单页应用」的静态前端成果，依据已合并的产品方案 `results/product/产品方案.md` 实现（关联任务 #6 / 计划 #4）。

## 一、如何打开

- **直接双击 `index.html`**，或用任意现代浏览器打开即可使用。
- 无需安装依赖、无需联网、无需后端服务。
- CSS 与 JS 均已内联在本文件中（符合 issue 中“配套 CSS/JS”的意图，实现零依赖、双击即用）。

## 二、功能与操作

| 操作 | 方式 |
| --- | --- |
| 新增待办 | 在顶部输入框输入文字，按 `Enter` 或点击「添加」；去空白后为空不新增 |
| 完成 / 取消完成 | 勾选或取消条目左侧复选框；已完成文字加删除线并弱化 |
| 编辑 | **双击**待办文字，或点击右侧 `✎`；`Enter` / 点击别处保存，`Esc` 或点「取消」放弃；保存为空则视为删除该条 |
| 删除 | 点击条目右侧 `🗑`（点击即删） |
| 筛选 | 顶部「全部 / 未完成 / 已完成」标签切换，仅改变视图不改数据 |
| 未完成数量 | 「未完成」标签显示 `(N)`，底部显示「还剩 N 项未完成」；`N=0` 时显示「全部完成」 |
| 空状态 | 当前视图无条目时显示对应提示文案 |

**数据保存**：所有改动即时写入浏览器 `localStorage`（键名 `todo-app:v1`），刷新或重开浏览器数据不丢失。

## 三、已知限制

- **仅本机本浏览器**：数据存在当前浏览器的 `localStorage` 中；更换浏览器、设备或清除浏览器数据后不会保留，也不与他人共享。
- **非目标功能（本期不做）**：账号体系、注册登录、云同步、多人协作、消息提醒、后端服务；以及排序拖拽、截止日期、优先级、标签等扩展字段。
- **删除不可恢复**：按产品方案 §4.4，删除为「点击即删」，不弹二次确认、不提供撤销。
- **隐私/无痕模式**：部分浏览器的无痕模式可能限制 `localStorage`，此时数据无法持久化。
- **浏览器支持**：面向最新版 Chrome / Edge / Firefox / Safari，不支持 IE。
- **单文件形态**：CSS/JS 内联在 `index.html` 内，便于直接打开；如需拆分工程化，可后续调整。

## 四、核对方式

- 打开 `index.html`，依次执行：新增数条 → 勾选完成 → 双击编辑 → 删除 → 切换三种筛选（观察列表与未完成数量变化）→ 刷新页面确认数据仍在。
- 缩放窗口或使用手机视图，确认桌面端与移动端布局均可用、无横向滚动。
- 打开浏览器开发者工具 Console，确认无报错。
- 本目录 `screenshots/` 附桌面端（1280px）与移动端（375px）自动验证截图。
