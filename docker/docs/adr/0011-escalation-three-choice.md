# 升级裁决必须三选一（含终止）

## Context
「极简待办清单」整链实测：2 轮改稿后升级审批人，但升级消息只给 **A 认可 / B 继续修改**，**漏了 C（暂停/终止）**。根因：`SKILL.md` 的异议段仅写"ask for a decision"，未要求列出选项，模型自由发挥时漏项；而"终止→回帖"（ADR 0010）需要审批人能看到并用"终止"选项。

## Decision
在 `SKILL.md` 计划异议段与上游成果异议段，把"请审批人/升级人裁决"明确为**三选一**：
- 接受当前稿（继续）；
- 继续修改（并指明具体修改点）；
- 终止该计划。
审批人/升级人据此裁决并执行；终止即走 `stop`，由 ADR 0010 的引擎事件回帖。

## Consequences
- 升级消息稳定包含"终止"选项，审批人可直接选择，不再隐含。
- 与 ADR 0006（改稿≤2 轮升级）、ADR 0010（终止回帖）配套闭环。

## Verification
- 禁词扫描通过；精选套件 169 通过（含 cards/model-surface/stop-notices）。
- 部署后复测升级消息应出现"接受/改稿/终止"三项。
