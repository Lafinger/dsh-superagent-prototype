# 客户需求文档：个人待办清单（Todo）单页应用

## 1. 背景与目标

我希望有一个可以在浏览器里直接打开的“待办清单”网页应用，帮我管理每天要做的事。不需要注册登录，打开就能用，数据保存在本机。

## 2. 目标用户

个人用户（先给我自己用）：需要快速记录待办、标记完成、随时查看还剩哪些没做。

## 3. 核心功能需求

- 新增待办：输入一句话即可添加一条待办。
- 完成 / 取消完成：可勾选标记完成，也可取消勾选。
- 编辑：可修改已添加待办的文字。
- 删除：可删除单条待办。
- 列表与筛选：支持「全部 / 未完成 / 已完成」三种视图切换，并显示未完成数量。
- 本地持久化：刷新或重新打开浏览器后，数据仍然存在（保存在浏览器本地）。
- 空状态：没有待办时给出友好提示。

## 4. 界面与交互期望

- 单页应用，移动端和桌面端都能正常使用（响应式布局）。
- 顶部是标题与新增输入框；下方是筛选与列表；常用操作尽量直观。
- 语言：简体中文。
- 视觉简洁清爽、阅读舒适即可。

## 5. 非目标（本次不做）

- 不做账号体系、云同步、多人协作、消息提醒、后端服务。

## 6. 验收标准

- 能新增、完成、编辑、删除待办，刷新后数据不丢失。
- 三种筛选视图切换正确，未完成数量正确。
- 移动端与桌面端布局可用，浏览器控制台无报错。

## 7. 交付要求

- 交付一个可直接在浏览器打开的静态网页（HTML / CSS / JS），无需安装依赖或后端。
- 附带简短的使用说明与已知限制。
